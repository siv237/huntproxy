# Источники проекта: что где читать

Указатель по документации, чтобы агент не дублировал доки в вики, а знал, куда
идти за первоисточником. Детальные описания живут в самих файлах.

## Первоисточники (актуальны)

- `README.md` / `README.{ru,de,es,fr,zh}.md` — пользовательское описание:
  возможности, порты, команды, конфигурация. Источник истины для поведения UI.
- `MODULES.md` — автогенерируемая карта модулей (строки, публичные API, импорты,
  связность). **Не редактируется руками**, пересобирается `./test.sh --map`
  (`scripts/module_map.py`). В вики не дублируется.
- `docs/proxy-check-workflow.md` — главный документ пайплайна проверки; там же
  актуальная формула score (`:160-184`) и антифрод v3 (`:463-502`). Источник
  истины для рейтинга наравне с `hunt/models.py`.
- `docs/quality-control-report.md` — манифест качества: уровни тестов и пороги
  (`:69-85`), архитектурные инварианты (`:102-112`).

## Проектные планы (реализованы)

- `docs/ROUTING_PLAN.md` — проектирование маршрутизации; реализовано, см.
  [routing](routing.md).
- `docs/SCHEDULER_PLAN.md` — проектирование планировщика; реализовано, см.
  [scheduler](scheduler.md).

## Устаревшее (не верить)

- `docs/ANALYSIS.md` — ранняя аналитика с **устаревшей** аддитивной формулой
  score (`:171-180`). Хранить как историю; текущую формулу см. [rating](rating.md).

## Фабричные данные

- `sources/default.ini` — фабричные источники (`[proxy]`, `[ip_blacklist]`,
  `[blocklist:<id>]`), парсится `hunt/constants.py:39-101`. Не путать с
  каталогом `wiki/raw/`.
- `llm-wiki.md` (корень) — исходный шаблон паттерна «LLM Wiki». Схема,
  реализованная в `AGENTS.md`.
